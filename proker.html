Program Kerja Tahunan

Program kerja tahunan merupakan agenda utama PRAJA 21 yang dilaksanakan setiap tahun sebagai bentuk pengabdian, kebersamaan, dan pelestarian tradisi masyarakat RT 02 RW 01 Desa Munding.

Program Rutin

Program Kerja Rutin

Program kerja rutin merupakan kegiatan yang dilaksanakan secara berkala sebagai upaya mempererat ukhuwah, menjaga tradisi, dan meningkatkan kepedulian sosial di lingkungan RT 02 RW 01 Desa Munding.

Ziarah

Kegiatan ziarah ke makam ulama maupun tokoh masyarakat sebagai bentuk penghormatan kepada para pendahulu serta sarana mempererat kebersamaan antaranggota.

Program Rutin

Tahlilan

Kegiatan doa dan tahlil bersama yang dilaksanakan secara berkala untuk memperkuat ukhuwah Islamiyah serta mendoakan para pendahulu.

Nilai Program Kerja

Prinsip Pelaksanaan Program

Seluruh program kerja PRAJA 21 dilaksanakan berdasarkan nilai-nilai kebersamaan, gotong royong, serta kepedulian terhadap lingkungan dan masyarakat.

Kebersamaan

Setiap kegiatan dilaksanakan dengan semangat kekeluargaan dan saling mendukung antaranggota.

Gotong Royong

Seluruh anggota berpartisipasi aktif dalam menyukseskan setiap program kerja organisasi.

Kepedulian

Program kerja diarahkan untuk memberikan manfaat bagi anggota maupun masyarakat sekitar.

Berkelanjutan

Setiap program diharapkan dapat terus dilaksanakan dan dikembangkan oleh generasi berikutnya.

PRAJA 21

Persatuan Remaja RT 02 RW 01 Desa Munding yang menjadi wadah generasi muda dalam membangun kebersamaan, kepedulian sosial, serta semangat berkarya bagi masyarakat.
